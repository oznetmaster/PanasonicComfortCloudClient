# PanasonicComfortCloudClient

An independent typed C# 14 API client for Panasonic Comfort Cloud, including Aquarea air-to-water heat pumps. Targets .NET 10 and .NET Framework 4.7.2, with a Windows test console.

Start with [authentication](guides/AUTHENTICATION.md), [protocol coverage](guides/PROTOCOL.md), [console usage](guides/CONSOLE.md) and [validation status](guides/VALIDATION.md). Browse the [API reference](reference/index.md) for typed models and methods.
